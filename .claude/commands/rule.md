# ルールを全部目視してからタスクに入る

タスクに着手する前に、適用されるルールを**全文**読んで把握する。つまみ食い・要約読み禁止。

Blitzdrache0で読むものは次の3つである。すべて絶対パスで読む。

1. `.claude/global-reference/全プロジェクト共通CLAUDE.md`（全リポジトリ共通の規約。マシンの`~/.claude/CLAUDE.md`が読める環境ならそちらでもよいが、内容が食い違ってもこの複製に従う）
2. `CLAUDE.md`（このリポジトリのRust版コーディングルール）
3. `_doc/計画/ユビキタス言語.md`（用語定義。命名と文章の判断はここを正本にする）

作業の種類によって、次も読む。

- エディター・編集画面・可視化を作る、または直す: `.claude/skills/エディター制作/SKILL.md`
- 新しいサブシステム・新機能を書き始める: `.claude/skills/アーキテクチャ先行/SKILL.md` と `.claude/skills/layer-roles/SKILL.md`
- 長い文書を書く、または直す: `.claude/skills/doc-writing/SKILL.md`
- 設計正本がある領域を触る: `_doc/設計/` の該当ファイル（親が指定する。指定が無ければ`README.md`のドキュメント節から探す）

把握が済んだら、**そのまま同じ流れでタスク本体に着手する**。「ルールを把握しました、指示があれば着手します」と停止して確認を返すのは禁止。ルール読了は作業の準備であって完了地点ではない。タスクが既に与えられているなら読了後ただちに実行し、完遂してから報告する。
