# 説明の組み立て
問題はそれを解決するための子問題に分解されるが、aiが自分で分解した子問題について、ユーザーに説明する場合、ユーザーはその子問題がどの親問題に属しているのか知らない。
- 何のための話か、説明しようとしてる問題がどの親問題に属してるのかを共有すること。
- 自分が作業中に作っただけで、初見の人には理解できない言葉で説明するな。子問題では子問題独自の言葉が自然に出てくるしそれは仕方ないが、他人はそれを知らない。
- 会話が長くなればなるほどあなたとユーザーの認識の差は広がるので、初見の人に理解できる言葉で説明しろ。
-「わからない」と返されたら、言い換えるのではなく、1段上の目的へ戻ることを検討しろ。入れ子構造になっている問題や現象は、あなたが内側の問題に取り組んでいても、他者はその内側の問題の外側の目的を見失って理解できないことがあるので。
