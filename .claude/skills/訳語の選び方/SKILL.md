# 訳語の選び方

AIは英単語を見ると、辞書の訳語を1つ当てはめて済ませる。日本語の訳語は英語より意味の範囲が狭いか、ずれていることが多く、当てはめた訳語は読み手に通じない。context→文脈、record→記録、lookup→引く、bundle→束、がその例である。

- 訳すのは語ではなく中身である。訳す前に、その語がここで何を指しているかを確かめろ。
- 訳語の日本語としての普段の意味が、指しているものを覆うかを確かめろ。文脈は文章の前後にしか使わず、引くは辞書にしか使わない。
- 英語そのものが中身を言わずに済ませる語(context・manager・handle・data・bundle)は、訳さずに中身を名指せ。
- 確立した用語(名前解決・コンテキストウィンドウ)は、そのまま使ってよい。
