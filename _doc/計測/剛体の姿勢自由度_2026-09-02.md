# 剛体の姿勢自由度のCPUの参照計算の検証(2026-09-02)

剛体の状態と接触の実装順1(Issue #39)の公式記録である。判断8の予測(陰的なジャイロ項)の反証・判断9の補正の分配・判断10の3つの検証拘束の収束を、`blitz_sim::rigid_xpbd`のCPUの参照計算で確かめた一次記録を記す。正本は`_doc/設計/剛体の状態と接触.md`(判断8・9・10・22、進行の記録)であり、検査の入口は`cargo test -p blitz_sim rigid`(28本)である。判断8の観測値は`cargo test -p blitz_sim prediction_observation -- --nocapture`で同じ値が出る。本記録はログ型であり追記のみ。

## 条件と由来

- 2026-09-02、CPUだけ(単精度。GPU経路はIssue #43)。主慣性(1, 2, 3)[kg·m²]・質量1[kg]・細分の刻み幅1/480秒(基本刻み1/60秒の8細分)・外力なし・拘束なしの自由回転を判断8の題材とする(正本が指定した値)
- 角速度の状態は判断9の速度の再構成(ω = 2·vec(q ⊗ q_前⁻¹) ÷ h)の結果を保持し、次の細分の予測がそれを読む(正本のとおり)。「予測だけ」と断った行は、予測が返した角速度をそのまま次の細分へ渡し再構成を通さない経路である
- 角運動量の大きさは R(q) I_ℓ R(q)ᵀ ω の長さ(局所へ回した角速度に局所の慣性を掛けた長さ)であり、初期値に対する比で読む

## 公式値1: 判断8の予測の反証4つ

| 検査 | 初期角速度[rad/s] | 経路 | 結果 |
|---|---|---|---|
| (1)発散しない | (3, 7, 5) | 全体、1/480秒×600細分 | 角運動量の比0.95987(途中の最大0.99994)。増加は無く、減少側に4.0パーセント |
| (2)散逸が刻み幅とともに減る | (3, 7, 5) | 全体、1/960秒×1200細分(同じ実時間1.25秒) | 比0.97928。減少量は1/480秒の約半分 |
| (3)中間軸の反転 | (0.01, 10, 0) | 全体、陰的1段 | 699細分目に局所の中間軸の成分の符号が反転 |
| (3)の反証 | (0.01, 10, 0) | 全体、ジャイロ項を省く | 4000細分まで反転しない |
| (4)陽的の発散 | (0, 200, 150) | 予測だけ、陽的に足す | 17細分目に比が2を越え、その後に非数へ発散 |
| (4)の対照 | (0, 200, 150) | 予測だけ、陰的1段 | 100細分後の比0.8514(正本の見積り0.85と一致) |
| (4)を全体の経路で | (0, 200, 150) | 全体、100細分 | 陽的は最大0.9710・最後0.3717、陰的は最後0.3927。どちらも2を越えない |

- **陰的1段は正本の保証(発散しない・散逸が刻み幅とともに減る)を満たし、中間軸の反転を再現する。** 反証(省く・陽的)はいずれも固定した性質を破る
- **判断9の速度の再構成は角速度の大きさを 2 ÷ h に抑える。** 1次の形 ω = 2·vec(Δq) ÷ h は |vec(Δq)| ≤ 1 のため |ω| ≤ 2 ÷ h(1/480秒で960 rad/s)を越えられず、正規化を挟んだ1細分の回転で |ω| は 1 ÷ √(1 + (h|ω|/2)²) 倍に縮む。(1)の4.0パーセントの減少はこの縮みが主因であり(|ω| = 9.1で1細分あたり約9e-5)、後退オイラー法の散逸より大きい。(4)の陽的な発散が全体の経路で観測できないのも同じ理由であり、予測の角速度をそのまま次の細分へ渡す経路で反証を固定した。この抑えは正本の1次の形の性質であり、細分1本で半回転に近づく角速度は仕様の外である
- ε(角運動量の増加の許容)は正本の暫定値1e-2のまま置く。増加は観測されていない(途中の最大0.99994)

## 公式値2: 判断9の補正の分配

- 補正の適用の関数(Δλ固定): 腕0の点への乗数は回転を生まず並進だけを生む。腕(1, 0, 0)へ上向きの乗数を与え、質量を2倍にすると並進の補正が半分になり回転は同じ、主慣性を2倍にすると回転の補正が半分になり並進は同じ(単精度で1e-6以内)
- 一回の射影の全体: 質量2・主慣性(1, 2, 3)の剛体の局所点(1, 0, 0)を、そこから y に0.1メートル離れた世界固定点へ硬い目標拘束で1回射影すると、乗数 −d ÷ w̃(w̃ = 1/2 + 1/3)、並進 (0, w d ÷ w̃, 0)、回転 (0, 0, d ÷ (w̃ J₃)) と1e-6以内で一致
- 再構成した角速度: 微小回転(0.002, −0.001, 0.0005)[rad]を1/480秒で割った解析値と相対1e-4以内で一致

## 主張できる範囲

- 言えること: 判断8の予測・判断9の補正と速度の再構成・判断10の3つの検証拘束と剛体と点の距離拘束が、CPUの参照計算で正本の式のとおりに動き、解析解と反証で固定されている。角速度の再構成は角速度の大きさを 2 ÷ h に抑える
- 言えないこと: GPU経路(Issue #43)・接触(Issue #40)・関節(Issue #41)は測っていない。細分数と反復回数の品質と費用の関係(判断19の実測)はIssue #40の箱の塔の日に採る。ねじり拘束の異方な慣性での軸の傾きの変化が関節の見た目に与える影響はIssue #41で扱う
