# 剛体の接触の静止摩擦・動摩擦・反発の検証(2026-09-03)

剛体の状態と接触の実装順2(Issue #40)の段2の公式記録である。判断13の静止摩擦・判断14の速度段階・判断16の接触の履歴を、`blitz_sim::contact` のCPUの参照計算で確かめた一次記録を記す。正本は `_doc/設計/剛体の状態と接触.md`(判断13・14・16、進行の記録)であり、検査の入口は `cargo test -p blitz_sim contact`(47本)である。本記録はログ型であり追記のみ。

## 条件と由来

- 2026-09-03、CPUだけ(単精度。GPU経路はIssue #43)。重力9.81メートル毎秒毎秒、基本刻み1/60秒を8細分(細分の刻み幅1/480秒)
- 場面は一辺1メートル・質量1キログラムの立方体1つと、半分の長さ20メートル(落下の場面は5メートル)の静的な直方体1つである。接触は面と面であり接触点は4つになる
- 細分の工程は試験専用の材料(`contact/scene/`)であり、予測 → 接触点集合 → 履歴の併走 → 反復(全部の非貫通 → 全部の静止摩擦)→ 速度と角速度の再構成 → 速度段階、の順で回す。本物の工程は後続の便が組む
- 反復回数は4、速度段階の巡回数は4である。判断19が挙げた初期値の候補(反復回数1)から増やした理由は下の「品質の設定の由来」に書く

## 公式値1: 判断13の坂の静止摩擦(静止摩擦係数0.6・動摩擦係数0.2)

| 検査 | 条件 | 結果 |
|---|---|---|
| 緩い坂で止まる | 傾きの正接0.2、3600刻み | 坂に沿った変位 1.08e-5メートル(基準は1ミリメートル以下) |
| 急な坂で滑り出す | 傾きの正接0.9、100刻み | 坂に沿った変位 6.96メートル |
| 位置の静止摩擦を外した反証 | 傾きの正接0.2、3600刻み、静止摩擦の射影を飛ばして押し戻した点を滑走中と印す | 坂に沿った変位 0.593メートル(毎細分 g sinθ h² ずつ下る) |
| 等方性(保持) | 傾きの正接0.2、鉛直軸まわり0度・30度・45度、600刻み | 変位 1.03e-5 / 1.06e-5 / 1.15e-5メートル |
| 等方性(滑走) | 傾きの正接0.9、同じ3つの回し、100刻み | 下り向きの速さ 8.455 / 8.469 / 8.784メートル毎秒(差は3.9パーセント) |

判定そのものの等方性は場面でなく射影の単体試験が固定する。接線変位の向きを接平面の中で30度ずつ12方向へ回しても、乗数の増分の大きさと円錐を超えるかどうかが1e-6以内で変わらない。場面に残る3.9パーセントの差は、接触点集合が返す4点の並びが世界の軸に対する箱の向きで変わり、逐次の射影がその順で解くことによる(45度の場合が最も離れる)。

## 公式値2: 判断14の動摩擦と反発

| 検査 | 条件 | 結果 |
|---|---|---|
| 滑走の減速度 | 傾きの正接0.9、動摩擦係数0.2、初速1メートル毎秒、60細分の後の240細分で測る | 測定4.968、解析 g(sinθ − μ_d cosθ) = 5.104メートル毎秒毎秒(相対誤差2.7パーセント) |
| 跳ね返りの高さ | 高さ1メートルから落とす、反発係数0.8 | 測定0.6378、解析 e²h = 0.64メートル(相対誤差0.34パーセント) |
| 静置で跳ねない | 反発係数0.8の箱を食い込み1e-4メートルで置き3600刻み | 床からの隙間の最大 8.76e-6メートル |
| 動摩擦の上限 | 単体試験。接線の速さ2メートル毎秒・λ_n = 0.001に対し μ_d λ_n ÷ h が上限 | 上限 0.24ニュートン秒が効き、接線の速さは零にならない。λ_n = 1では |v_t| ÷ w̃_t が採られ接線の相対速度が零になる |
| 低速の抑制 | 単体試験。v_n⁻ の大きさが閾値の半分 | 反発の後の法線相対速度が零(反発係数0.8でも跳ねない) |

## 公式値3: 反証で分かった3つの取りこぼし

| 反証 | 実装 | 結果 |
|---|---|---|
| 速度段階を1巡だけにする | 反発を巡回させず、動摩擦と反発を1巡だけ適用する | 平らな箱の跳ね返りで角速度1.36ラジアン毎秒の偽の回転が残り、跳ね返りの高さが0.606メートル(5.3パーセント低い)になる |
| 円錐を超えた後も同じ細分で静止摩擦を判定し続ける | 滑走中の印が立った接触点にも毎反復で円錐の判定を行う | 置き直した錨からの新しい接線変位が円錐の内側に入り、位置の静止摩擦と速度の動摩擦が二重に効く。動摩擦係数0.4の坂の減速度が2.37(解析3.65)になり、実効の摩擦係数が μ_s の値へ寄る |
| 速度の単位方向を正規化せずに作る | `速度::単位方向` が成分をそのまま単位方向の生成へ渡す | 単位長でない入力が型付きエラーで拒まれ、動摩擦の衝撃が一度も適用されない(坂の箱が μ_d に依らず g sinθ で加速する) |

## 品質の設定の由来

- 反復回数は4である。判断19の初期値の候補は1だが、面と面の4点を1巡だけ解くと、非貫通の補正の回転が錨を接線方向へ大きく動かし、静止摩擦がその見かけの滑りを実際の滑りと区別できずに毎細分で円錐を超える。4・8・16・32で比べたところ4と32の差は0.5パーセント以内であり、4を採った
- 速度段階の巡回数は4である。1巡では上の反証のとおり偽の回転が残る。4巡で跳ね返り後の角速度は0.003ラジアン毎秒(1巡の1.36から)へ落ちる。動摩擦は1細分に1度だけ与える量であるため巡回の対象にせず、2巡目からは反発だけを適用する
- 細分数8・刻み幅1/480秒は判断19の初期値の候補のままである。箱の塔の実測(後続の便)で確定する

## 主張できる範囲

- 言えること: 判断13の静止摩擦がクーロン円錐の内側で坂の箱を保持し、超えると滑走へ移り、判定が接線の向きに依らない。判断14の反発が解析解 e²h と0.34パーセントで一致し、低速の抑制が静置の跳ねを断つ。判断16の履歴が1メートルの滑走のあいだ接触を継続として対応付ける
- 言えないこと: 判断14の滑走の減速度は正本が求める相対誤差1パーセントに届かず2.7パーセントである。原因は判断12が「隔たりが0以上の点では乗数を変えない」と定めるため乗数が細分の中で単調に増え、面と面の4点を逐次に解くと法線の乗数の合計が真の法線力積を9パーセント上回ることである(動摩擦の上限が μ_d λ_n ÷ h であるため、その分だけ摩擦が強く出る)。誤差は動摩擦係数に比例して増え、動摩擦係数0.4では5.5パーセント、0.55では20パーセントである
- 言えないこと: 静止摩擦が保持できる傾きの上限は静止摩擦係数そのものではない。面と面の4点で法線の乗数が分かれる一方、各点の静止摩擦は箱全体の滑りを1点で戻そうとするため、円錐の判定が点ごとに厳しくなる。傾きの正接0.2(静止摩擦係数0.6)は保持し、0.5は毎刻み微小に下る(3600刻みで0.89メートル)
- 言えないこと: 箱10段の塔・運動学的な床・質量比100:1・2回実行のビット一致は測っていない(判断17の島と判断18の休止と細分の工程が要るため、後続の便で測る)
