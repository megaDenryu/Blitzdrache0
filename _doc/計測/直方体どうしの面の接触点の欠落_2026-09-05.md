# 平行に重なった直方体の面の接触点が欠ける境目の計測(2026-09-05)

Issue #66「直方体どうしの接触点集合が、平行に重なった面から面と面の4点を返さない」の一次記録である。正本は `_doc/設計/剛体の状態と接触.md`(判断11・判断12)と `_doc/設計/世界の形と衝突基盤.md`(判断10)であり、検査の入口は `cargo test -p blitz_collision contact_set::box_pair_stack_tests` である。本記録はログ型であり追記のみ。

## 条件と由来

- 2026-09-05、`blitz_collision` の接触点集合の問い合わせだけを直接呼ぶ計測である。`blitz_sim` の細分・反復・予測を通していない
- 形は半分の長さ0.5メートルの立方体2つである。下の立方体の中心を高さ0.5メートルに置き、上の立方体を高さ1.5メートルから食い込みのぶんだけ下げ、Z軸まわりに傾ける
- 問い合わせの第1の形が下の立方体、第2の形が上の立方体である
- 私が測ったのはこの2つの立方体の1組だけである。塔10段の場面は測っていない(理由は下の「測っていないこと」に書く)

## 公式値1: 傾きと食い込みで決まる接触点の数(是正の前、接触生成の余白なし)

行が上の立方体のX軸まわりの傾き、列がZ軸まわりの傾きである。値は接触点の数である。

| 食い込み | X軸の傾き | Z軸の傾き 0度 / 1e-6度 / 1e-4度 / 1e-2度 / 0.1度 / 1度 |
|---|---|---|
| 1e-6メートル | 0度 | 4 / 4 / 4 / 2 / 2 / 2 |
| 1e-6メートル | 1e-4度 | 4 / 4 / 3 / 2 / 2 / 2 |
| 1e-4メートル | 0度 | 4 / 4 / 4 / 4 / 2 / 2 |
| 1e-3メートル | 0度 | 4 / 4 / 4 / 4 / 4 / 2 |
| 1e-2メートル | 0度 | 4 / 4 / 4 / 4 / 4 / 4 |

**境目は 0.5 sin(傾き) = 食い込み である。** 傾き θ は上の立方体の底面の角を 0.5 sin θ だけ持ち上げるため、持ち上げが食い込みを超えた角は参照面の平面より外側へ出て、切り抜きが落としていた。食い込み1e-3メートルでは傾き0.115度が境目であり、実測はその前後で4点と2点に分かれる。水平のずれだけを与えた場合(0から0.5メートルまで)は4点のまま変わらない。

## 公式値2: 特徴の識別が傾きの符号で入れ替わること(是正の前後で変わっていない)

食い込み1e-3メートル・水平のずれなしで、Z軸まわりの傾きを与えたときに返る特徴の識別である。

| 傾き | 4点の特徴の識別(第1の形 / 第2の形) |
|---|---|
| 0度(完全に平行) | 面Y+ / 頂点 の4つ |
| 1e-7度 | 面Y+ / 頂点 が2つ、辺Z+ / 辺X− が2つ |
| 1e-2度 | 同上 |

傾きが零でなければ、上の立方体の底面は下の立方体の上面に対して 0.5 sin θ だけ水平にずれる。ずれた側の2つの角は参照面を囲む側の平面の外に出るため、切り抜きが平面の上へ切り取り、その点の特徴が「参照面の辺と入射面の辺」になる。傾きの符号が変わると、どちらの2つが切り取られるかが入れ替わる。**これは幾何としては正しい答えであり、是正の対象にしていない。** 塔で特徴が入れ替わり続けるのは、公式値1の欠落が箱を毎細分で傾け直すためであると私は見ている。この見立ては塔で測って確かめていない。

## 公式値3: 是正の後(接触生成の余白0.005メートル)

食い込み1e-3メートル・半分の長さ0.5メートルの立方体2つで測った接触点の数である。

| Z軸まわりの傾き | 余白0.005メートル | 余白なし(反証) |
|---|---|---|
| 0度 | 4 | 4 |
| ±0.15度 | 4 | 2 |
| ±0.3度 | 4 | 2 |
| ±0.6度 | 4 | 2 |
| ±1度 | 2 | 2 |
| ±3度 | 2 | 2 |

余白を入れた後の境目は 0.5 sin(傾き) = 食い込み + 余白 であり、この条件では0.688度である。実測は0.6度で4点、1度で2点であり、境目と合う。

## 既知の2件の失敗への影響

`contact::scene::slope_tests::鉛直軸まわりに回しても正接零点五零と零点五五を保持し正接零点六一で滑走する` と `contact::scene::tolerance_boundary_tests::許容差が二倍になる場面でも保持できる傾きの上限が動かない`(Issue #59)は、是正の前後で同じ値で落ちる。前者が報告する保持できなかった量は是正の前も後も185.81473である。**この是正はこの2件を良くも悪くもしていない。**

## 測っていないこと(申告)

- **箱10段の塔を測っていない。** 複数の動的剛体を細分の工程で回す場面がリポジトリに無いためである。`blitz_sim` の `contact/scene/` は1つの動的な直方体と1つの静的な直方体だけの試験専用の場面であり、剛体どうしの接触を細分で回す入口を持たない。Issue #66 が引く「1細分あたり17.5点」「開始47パーセント」「円錐超過44パーセント」は、Issue #40 の3つ目の作業の途中で作られた場面での実測であり、その場面はリポジトリへ残っていない
- したがって、完了条件の「箱10段の塔で剛体どうしの接触点の総数が1細分あたり40点前後になること」と、Issue #40 の受入条件「600刻み以内に休止すること」は、この作業では確かめていない
- 公式値2で述べた見立て(特徴の入れ替わりが公式値1の従属である)を確かめていない
