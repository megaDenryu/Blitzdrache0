# 接触生成の余白を入れた塔が接触余白を超える後退の切り分け(2026-09-05)

PR #70(Issue #66の接触生成の余白)をPR #67(Issue #40の3つ目の作業)の上へ積んだ枝で、`contact::pipeline::tower_standing_tests::箱十段の塔が六百刻みのあいだ全部の接触の食い込みを接触余白以内に保つ` が落ちた事象の一次記録である。正本は `_doc/設計/剛体の状態と接触.md`(判断11・判断12・判断13)であり、計器の入口は `cargo test -p blitz_sim 塔の余白の内側の点が連立へどう効いたかを綴る -- --ignored --nocapture` である。本記録はログ型であり追記のみ。

## 条件

- 場面は `contact/pipeline/tower_fixture.rs` の箱10段の塔である。半分の長さ0.5メートルの立方体10個を静的な床の上へ積み、基本刻み1/60秒・細分数16・位置の反復2回・速度段階の巡回4回・摩擦係数0.5・反発係数0で回す
- 計器は `contact/pipeline/tower_margin_point_record.rs` である。刻みごとに全部の細分の接触拘束を受け取り、指定した1組の剛体について接触点1つずつの生成時の符号付き貫通量・細分の末の法線のラグランジュ乗数・有効集合への参加(法線反力の有無)・静止摩擦の錨の置き直しと滑走の印を綴る
- 剛体の配列添字0が床であり、1から10が下から順の箱である
- 実行はデバッグ構成である。時間は同じ機械の同じ日の値どうしだけを比べる

## 公式値1: 落ちるのは余白0.005メートルのときだけである

`blitz_sim` の `contact/contact_thresholds.rs` が持つ接触生成の余白だけを変え、他は一切変えずに測った。

| 接触生成の余白 | 600刻みの結果 | 実行時間 |
|---|---|---|
| 0メートル(余白を外した反証) | 通る | 43.50秒 |
| 0.0002メートル | 通る | 61.29秒 |
| 0.0005メートル | 通る | 77.13秒 |
| 0.001メートル | 通る | 120.74秒 |
| 0.002メートル | 通る | 87.20秒 |
| 0.005メートル(この変更の値) | 刻み91で第1段と第2段の食い込み0.005360484 | (91刻みで打ち切り) |

**この変更が選んだ0.005メートルだけが落ちる。** 0.002メートルまでは通る。余白は接触点の数を増やすため実行時間も増える(余白0メートルの43.50秒に対し、0.0002から0.002メートルでは61秒から121秒である)。

半分の長さ0.5メートルの箱では、余白0.005メートルは 0.5 sin θ = 食い込み + 余白 の境目を0.573度まで押し上げる。すなわちこの値は、箱が0.573度傾いて実際には触れていない角を接触解法の候補点として残す。この変更はこの値を「判断12の接触余白と同じ値」として選んでおり、余白そのものの導出を持っていない。**接触余白は非貫通の解が残してよい食い込みの上限であり、接触生成の余白は候補点を保つ範囲である。2つは別の量であり、同じ値を選ぶ理由が無い。**

## 公式値2: 落ちる直前の4つの量(余白0.005メートル、剛体2と剛体3の接触点集合)

刻み87の細分6までは、この接触点集合は3点から4点であり、参照面がY軸の面である(特徴の識別が「面Y+ / 頂点」「辺X / 辺Z」「頂点 / 面Y−」の混ざり)。細分7で1点へ落ち、以後64細分のあいだ1点のままである。落ちた後の特徴の識別は「辺X / 辺Z」と「辺Z / 辺X」であり、細分ごとにこの2つが入れ替わる。すなわち分離軸の最小が面の軸から2つの辺の向きの外積の軸へ移り、接触点集合が辺どうしの1点だけになっている。

1点になった後の細分ごとの値である。有効集合はすべて参加、錨の置き直しはすべて真である。

| 刻み | 細分0の符号付き貫通量 | 細分15の符号付き貫通量 | 細分15の法線の乗数 |
|---|---|---|---|
| 88 | +0.0006339 | +0.0019449 | 1.462312e-4 |
| 89 | +0.0023386 | +0.0039866 | 3.057409e-4 |
| 90 | +0.0047230 | +0.0061718 | 4.521578e-4 |
| 91 | +0.0075025 | +0.0074012 | 1.247744e-3 |

食い込みは細分ごとに単調に増え、細分の中でも減らない。法線の乗数は、この段が支える7キログラムぶんの解析値 m g h²(h = 1/960秒)である7.4e-5を6倍から17倍上回っており、押し戻しは効いているが1点では足りていない。**1点の接触は箱の傾きを止められないため、傾きが増えるほど外積の軸がますます浅くなり、面の軸へ戻らない。**

余白を0メートルにした同じ刻みでは、同じ組の接触点集合は面の軸と外積の軸のあいだを細分ごとに行き来し、1点になる細分はあっても連続せず、符号付き貫通量は1e-4メートルの桁に留まる。

## 公式値3: 余白の内側の点が偽の法線反力を作っているという見立ては誤りである

刻み87の細分0から細分6までに現れた、生成時の符号付き貫通量が負の点は次のとおりである(余白0.005メートル)。

| 細分 | 特徴の識別 | 符号付き貫通量 | 細分の末の法線の乗数 |
|---|---|---|---|
| 0 | 面Y+ / 頂点 | -0.0001123 | 3.970637e-5 |
| 1 | 頂点 / 面Y− | -0.0000942 | 6.705120e-5 |
| 2 | 面Y+ / 頂点 | -0.0001213 | 5.320965e-5 |
| 3 | 頂点 / 面Y− | -0.0000940 | 9.984802e-5 |
| 4 | 面Y+ / 頂点 | -0.0001113 | 5.423362e-5 |
| 5 | 頂点 / 面Y− | -0.0000962 | 0 |
| 6 | 面Y+ / 頂点 | -0.0000478 | 2.412317e-5 |

生成時に離れている点が細分の末に正の法線の乗数を持つことは、判断12に反していない。生成時の隔たりは細分の予測の直後の値であり、同じ接触点集合の他の点の補正がその点を実際に食い込ませた後は、その点は貫通している点である。判断12が禁じるのは「隔たりが0以上で乗数が0の点を読むこと」であって、反復の途中で食い込んだ点へ反力を与えないことではない。

**この読みが正しいことを反証で確かめた。** 混合連立の有効集合の候補を「貫通しているか、この細分で既に乗数を積んだ行」へ限る実装(法線だけの連立の開始の集合と同じ判定)を入れると、塔の受入条件が落ちる刻みは91から107へ動く一方、`contact::scene::slope_tests::静止摩擦係数の三分の二の坂の箱は三千六百刻みで一ミリメートル以下しか動かない` が正接0.4の坂で2737.8926メートルの変位を出して落ちる。候補を限ると、補正の後に食い込む点を有効集合へ入れ直す道が塞がり、相補条件を満たす部分集合が1つも見つからない細分が出て、混合連立が法線だけの連立へ落ちて静止摩擦が丸ごと消えるためである。したがって**余白の内側の点が偽の法線反力を作っているという見立ては誤りであり、この反証で退けた。** この実装は採らない。

余白の内側の点が力を出さないことそのものは、`contact::margin_point_reaction_tests` の3本が固定している。負の符号付き貫通量を持つ候補点が接触拘束として実在すること、その拘束の非貫通の射影が `離れている` を返して法線のラグランジュ乗数を積まないこと、その拘束の静止摩擦の仮の射影が `法線反力が無い` を返すことの3本である。

## 公式値4: 外積の軸を退ける偏りを入れると通る(採らなかった是正の実測)

分離軸の走査(`crates/blitz_collision/src/contact_set/box_pair_axis_search.rs`)で、2つの辺の向きの外積の軸を入れ替えるときの余地へ、既存の丸めの誤差の上界に加えて重なりの深さの一定割合を足す実装を試した。

| 偏り(深さに対する割合) | 接触生成の余白 | 600刻みの結果 |
|---|---|---|
| 0.002 | 0.005メートル | 通る |
| 0.01 | 0.005メートル | 通る |
| 0.05 | 0.005メートル | 通る |
| 0.002 | 0メートル | 通る |

**費用が桁で増える。** 偏りなしの同じ検査1本が43.50秒(余白0メートル)であるのに対し、偏りを入れた検査1本は25分を過ぎても終わらず、私はそこで打ち切った。上の表の合否は、この打ち切りより前に測った版(混合連立の有効集合の候補を貫通している行へ限る反証を同時に入れていた版)の値である。**合否は再現しているが、この表の版は最終の実装と同じではない。**

なお、この偏りは分離軸の最小の選び方そのものを変える。既存の `cross_axis_margin.rs` が置いているのは倍精度の丸めが作る偽の最小を退ける上界(尺度の2のマイナス43乗の桁)だけであり、いま落ちている場面はそれより桁が大きい実際の傾きで外積の軸が最小になっている。丸めの話ではなく「面で乗っている2つの直方体には面の接触点集合を返す」という幾何の契約の話であるため、この記録では実測だけを残し、実装は入れていない。費用が増えるのは、接触点集合が本来の4点から8点の面の接触へ戻り、判断13の有効集合が取りうる部分集合を全部走査する形(2の点の数乗)であるためである。1点の接触点集合では2通りしか無かった走査が、8点では256通りになる。偏りを入れるなら、有効集合の解き方を全走査でない形へ替えることが同時に要る。

## 結論

1. この後退は受入条件の誤りではない。**実装の欠陥である。** 塔の第n段と第n+1段の接触点集合が1点へ落ち、その1点が箱の傾きを止められずに食い込みが単調に増える
2. 欠陥は2つある。1つ目は、**接触生成の余白の値0.005メートルを、別の量である接触余白と同じにしたこと**である。この値は0.573度傾いて触れていない角を候補点として残す。公式値1のとおり、落ちるのはこの値のときだけであり、0.002メートルまでは通る。2つ目は、**分離軸の最小に2つの辺の向きの外積の軸が選ばれると接触点集合が1点になること**である(公式値2)。1つ目が2つ目を引いている
3. 余白の内側の点が偽の法線反力を作っているという見立ては、公式値3の反証で退けた
4. 値の選び直しはこの作業では行っていない。「塔が通る値」を選ぶことは、1つの場面へ定数を合わせることであり、導出ではないためである。導出の候補を報告に書いてオーナーの裁定へ回す
5. 塔の受入条件は落ちたままである。閾値は緩めていない

## 測っていないこと(申告)

- 接触生成の余白の値を導出していない。公式値1が言えるのは「0.005メートルで落ちる」「0.002メートル以下で通る」だけである
- 公式値4の偏りを入れた状態で `blitz_sim` の検査全体を回していない。塔の検査1本も最終の実装の上では完走させていない(25分で打ち切った)
- 有効集合の全走査を枢軸の移動へ替えた場合の費用を測っていない

## 追記(2026-09-05、接触生成の余白を導出値へ変えた後の実測)

私はこの日、接触生成の余白を固定値0.005メートルから細分の運動に由来する導出値へ変え、同じ塔の場面で測り直した。計器は `contact/pipeline` へ一時に置いた記録であり、測り終えて消してある。実行はデバッグ構成であり、時間は同じ機械の同じ日の値どうしだけを比べる。

### 公式値5: 運動の項だけの導出では塔が刻み437で落ちる

最初に測ったのは、運動の項 Δt (|ω_1| R_1 + |ω_2| R_2 + |v_1 − v_2|) を、下限に「非貫通の解法が食い込みと区別できない長さ」(座標の単精度の刻みから求めた量。この場面で3.1e-7メートル)、上限に「2つの形の薄い方の厚み」を置いて挟んだ形である。

| 量 | 値 |
|---|---|
| 600刻みの結果 | 刻み437で第2段と第3段の食い込み0.006309271が接触余白0.005を超えて落ちる |
| 導いた余白(96000件) | 最小3.10e-7・中央2.93e-4・平均4.01e-4・95パーセント点1.09e-3・最大6.13e-3 |
| 第1段と第2段の対の接触点の数(9600細分) | 0点249・1点5122・2点738・3点564・4点2247・5点79・6点601 |

落ちる直前の第2段と第3段の対は、刻み433の細分1から連続して1点になり、以後戻らない。刻み430から432の余白は最小1.6e-4から最大1.2e-3であり、公式値1で通ることが分かっている0.0002から0.002の帯の中にある。**したがって落ちた原因は余白の大きさではない。**

### 公式値6: 同じ実装で固定値0.0002メートルは通る

公式値5と同じコードで、導出の戻り値だけを固定値0.0002メートルへ差し替えて測った。600刻みを通り、65.10秒である。導いた余白の中央値2.93e-4はこの固定値と同じ桁である。**大きさが同じ桁でも、固定なら通り、細分ごとに動くと落ちる。** すなわち欠陥は余白が細分ごとに動くことにある。角が候補点として残るかどうかの境目が細分ごとに動くと、幾何が動かなくても候補点が入れ替わり、Issue #66が消そうとした「接触点の数と特徴の識別が細分ごとに入れ替わる」状態がそのまま戻る。

### 公式値7: 静穏の閾値から下限を求めると塔は600刻みを通る

上の反証から、下限を「判断18が静穏と判定する速さで動く対の角がその細分に動きうる長さ」 Δt (ω_休止 (R_1 + R_2) + v_休止) へ置き替えた(ω_休止 = 0.05ラジアン毎秒、v_休止 = 0.01メートル毎秒、Δt = 1/960秒)。判断18がこの速さ以下の剛体を動いていないものと見なす以上、その対の候補点を保つ範囲を細分ごとに動かしてはならないためである。座標の刻みから求めた下限も残し、2つの大きい方を採る。

| 導いた余白(96000件) | 最小1.0063e-4・中央2.28e-4・平均3.24e-4・95パーセント点7.93e-4・99パーセント点1.07e-3・最大4.85e-3 |

最小値1.0063e-4は、半分の長さ0.5メートルの立方体2つ(外接半径0.8660254メートル)に対する Δt (0.05 × 0.8660254 × 2 + 0.01) = 1.00628e-4 と一致する。すなわち静穏な対では余白がこの下限で一定になり、細分ごとに動かない。

### 公式値8: 導出は Issue #75 を直していない

公式値7の実装でも、第1段と第2段の対は9600細分のうち3359細分で1点である。1点になる細分は連続せず、面の軸と外積の軸のあいだを行き来する。公式値2が記録した「1点が64細分連続して食い込みが単調に増える」形にはならないため塔は立つが、分離軸の最小に外積の軸が選ばれる欠陥そのものは残っている。この欠陥はIssue #75の担当であり、この作業では触れていない。

## 追記(2026-09-05、形の厚みによる上限を外した後の実測)

私はこの日さらに、オーナーの裁定に従って接触生成の余白の導出から上限(2つの形の薄い方の厚み)を外し、同じ塔の場面で測り直した。裁定の理由は、上限を先に掛けてから下限を適用する実装では下限が上限を超える場面で最終値が上限を破っており、契約と実装が同時に成立していなかったこと、および厚みの無い三角形が形として存在する以上、形の最小の厚みは接触生成の余白の普遍的な上限ではないことである。導出は max(細分中の相対運動から導いた長さ, 静穏とみなす運動から導いた下限, 解法が区別できない長さの下限) になった。計器は導出へ一時に置いた出力であり、測り終えて消してある。実行はデバッグ構成である。

### 公式値9: 上限を外しても塔の余白の分布が動かない

| 量 | 上限あり(公式値7) | 上限なし(この作業) |
|---|---|---|
| 600刻みの結果 | 通る | 通る |
| 最小 | 1.0063e-4 | 1.006277e-4 |
| 中央 | 2.28e-4 | 2.277144e-4 |
| 平均 | 3.24e-4 | 3.239713e-4 |
| 95パーセント点 | 7.93e-4 | 7.925520e-4 |
| 99パーセント点 | 1.07e-3 | 1.067390e-3 |
| 最大 | 4.85e-3 | 4.851634e-3 |

件数はどちらも96000である。**最大値が動かないことが、この上限が塔の場面で一度も効いていなかったことの直接の証拠である。** 上限であった値は半分の長さ0.5メートルの立方体2つの薄い方の厚み1.0メートルであり、測った最大値4.85e-3メートルはその206分の1である。すなわち塔では運動の項が上限へ届く細分が1つも無く、上限を外したことで塔の挙動は動いていない。撤回で実際に変わるのは、上限が下限を下回る場面(厚みの無い板・三角形が相手の場面)と、運動の項が形の厚みを超える高速の場面の2つである。

### 公式値10: 厚みの無い板が相手でも余白が下限を下回らない

上限を外す前の実装では、厚みの無い板(3軸のうち1軸の半分の長さが0の直方体)が相手のとき上限が0になり、実装は下限を後から適用していたため最終値は下限になっていた。すなわち実装は本文が書いた上限を破ることで正しく動いていた。上限を外した後の実装では、静止した立方体と厚みの無い板の対の余白が Δt (0.05 (0.8660254 + 0.7071068) + 0.01) = 1.8470e-4 メートル(反証の刻み幅 Δt は480分の1秒である)になる。この値は `contact::generation_margin::derivation_tests::厚みの無い板が相手でも余白は静穏の閾値から求めた下限を下回らない` が固定した。頭打ちが無いことは同じファイルの `運動の項が下限を超えるときは幾何の上限で頭打ちにならない` が固定しており、こちらは角速度1000ラジアン毎秒の立方体で運動の項1.804メートルがそのまま余白になること(立方体の厚み1.0メートルを超えること)を確かめる。

## 追記(2026-09-05、静穏の下限の並進の項を 2 v_休止 へ直した後の実測)

私はこの日さらに、PR #70の再レビューの指摘に従って静穏の下限の並進の項を1物体分の v_休止 から2物体分の 2 v_休止 へ直し、同じ塔の場面で測り直した。直した理由は、判断18が静穏を島の各動的剛体について |v| ≤ v_休止 で判定するため、静穏な2つの剛体の相対の並進速度が三角不等式から |v_1 − v_2| ≤ |v_1| + |v_2| ≤ 2 v_休止 になり、1物体分の v_休止 では静穏と判定される対のすべてを覆えないことである。下限は Δt (ω_休止 R_1 + ω_休止 R_2 + 2 v_休止) になった。計器は導出へ一時に置いた出力(導いた余白を1件ずつ綴る行)であり、測り終えて消してある。実行はデバッグ構成である。入口は `cargo test -p blitz_sim 箱十段の塔が六百刻みのあいだ全部の接触の食い込みを接触余白以内に保つ -- --nocapture` である。
