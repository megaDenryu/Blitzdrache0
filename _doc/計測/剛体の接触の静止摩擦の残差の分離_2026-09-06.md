# 剛体の接触の静止摩擦の残差の分離(2026-09-06)

[Issue #59](https://github.com/megaDenryu/Blitzdrache0/issues/59)「静止摩擦の保持・滑走境界を座標の単精度と解法許容差から独立させる」の第2段階の一次記録である。第1段階の記録は `_doc/計測/剛体の接触の静止摩擦の数値契約の診断_2026-09-06.md` である。正本は `_doc/設計/剛体の状態と接触.md`(判断24)である。本記録はログ型であり追記のみ。

この段階で入れた解法の変更は1つである。**静止摩擦の行が閉じるべきだったのに閉じなかった接線変位(持ち越す接線の残差)を接触の履歴が1細分だけ持ち越し、その量が1細分で動いたぶんを位置から再構成した速度から除く。** 契約の全文は判断24にある。

## 結論を先に書く

**候補Dは単独では第1段階が見つけた周期を消さない。** 位置から再構成した下り向きの速さの符号の反転は、64細分のうち46回(是正の前)から39回(是正の後)へ15パーセント減っただけである。判断24が置いた反証(a)の閾値4回には遠い。Issue #59の完了条件のうち「正接0.55を3方向とも保持」と「許容差0.5/1/2倍で分類が変わらない」は、この段階でも成立していない。

一方で、この変更が入れた害は無く、副次の改善が1つある。既存の検査で落ち方が悪くなったものは無く、`tolerance_boundary_tests` は「もとの場面が走査の下端0.45でも保持しない」から「0.46まで保持する」へ動いた(どちらもデバッグ構成の測定である)。

## 途中で見つけた2つの欠陥と、その是正

第2段階の実装のあいだに、契約の側の穴を2つ見つけた。どちらも実測が先に出て、そこから契約を直した。

**1つ目は、粘着の候補が確定しなかった細分を残差の対象に含めていたことである。** 混合の連立が「相補条件を満たす有効集合が無い」か「表現の精度が不足した」を返した細分は、法線だけの連立へ落ちる。この細分の錨の接線変位は静止摩擦が1度も閉じておらず、残っているのは滑りそのものである。これを残差として持ち越すと、次の細分でその滑りを丸ごと速度から引くことになる。実測では、水平な床の上で秒速2メートルで滑らせた箱が0.052メートルで止まった(是正の前は1メートル以上滑る)。判断24へ破棄条件5として書き、粘着の候補を確定した印を一細分の解の状態へ足した。

**2つ目は、仮の補正を配置へ足してから速度を割り出していたことである。** 打ち消したい量は許容差 δ の1個分と半分(1.7e-6メートルと0.85e-6メートル)であるのに対し、接触が世界の原点から20.5メートルにあるため単精度の位置の表現の刻みは1.9e-6メートルである。配置へ足しても位置のビットが変わらず、速度は元のまま残る。実測では、この形の反証(a)は符号の反転52回であり、是正の前の46回より悪かった。速度の領域で足す形(v = (x − x_前) ÷ h + Δx̂ ÷ h)へ直して39回になった。判断24の式もこの形へ書き直した。

39回は46回より少ないが、4回には遠い。したがって**位置の刻みに負けていたことは原因の一部でしかなく、周期の主因は別にある。**

## 観測から言えること

**1. 跳んでいるのは重心のz成分であり、跳びはちょうど1刻みである。** 鉛直軸まわりの回しが0度のとき、坂の面の法線は (0, cosθ, sinθ) であり、坂の下り向きはy軸とz軸の張る面にある。箱の重心は坂の中心から法線の向きへ20.5メートル進んだ点であるから、正接0.50では y = 20.5 cosθ = 18.3358、z = 20.5 sinθ = 9.168 である。表のy成分のビット列 0x4192afa1 の値は 18.335756 であり、この計算と一致する。

- **y は17細分のあいだ1ビットも動かない。** この帯の単精度の刻みは 2^-19 = 1.9073e-6 メートルであり、解法の補正がこれより小さいためである。この刻みは第1段階が求めた許容差 δ と同じ量である(δ の定義がこの座標の刻みだからである)
- **z は毎細分1刻みずつ前後する。** この帯の刻みは 2^-20 = 9.5367e-7 メートルである
- 下り向きの単位ベクトルのz成分は cosθ = 0.894427 であるから、z が1刻み動いたときの坂に沿った変位の変化は 9.5367e-7 × 0.894427 = **8.529922e-7 メートル**である

観測した跳び **8.529933e-7 メートル**との比は 1.0000012 であり、7桁で一致する。**すなわち箱は、坂の面に垂直な向きへは1刻みも動けないまま、坂に沿う向きに座標の隣り合う2つの表せる値のあいだを行き来している。** 姿勢の側ではない。四元数の成分の刻みは値が1に近い成分で 6e-8 であり、腕0.5メートルを掛けても 3e-8 にしかならず、8.53e-7 には桁が2つ足りない。

**2. 周期は位置の側にあり、速度の側ではない。** 変位の変化は +1.705983e-6 → 0 → −8.529896e-7 → +1.705983e-6 の4つを繰り返す。この並びは、除く経路でも運ばせる経路でも同じである。位置から割り出した速さ(引く前)も両経路で同じ 8.188725e-4 と −4.094362e-4 と 0 を繰り返す。契約が変えるのは引いた後の速さだけであり、次の細分の位置がどの刻みへ跳ぶかを変えていない。

**3. 錨から測る残差は、位置の量子化の跳びを写していない。** 引く前の速さ 8.188725e-4 に細分の刻み幅を掛けると 1.705983e-6 メートルであり、これは z の**2刻み**に当たる。一方その細分の残差の変化は 8.5299e-7 メートル(**1刻み**)であり、引いた後の速さは 6.550993e-4(20パーセント減)から 4.911154e-4(40パーセント減)にしかならない。位置が 1.705983e-6 メートル動いた細分(細分3・7・11・15)の残差の変化は 8.5299e-7 メートルか、細分によっては 0 である。残差は接触点の接平面で測った長さであり、重心が坂に沿って跳んだ長さと同じ量ではない。したがって、その差を引いても速度の跳びは残る。位置の跳びを速度から丸ごと除くには、跳びそのものを測る必要がある。

**4. したがって候補Dは単独では周期を消せない。** 消すべき往復は「解法が閉じ残した長さ」ではなく「配置が表せる刻みの間を行き来していること」である。往復の正体は、解法の補正が単精度の位置の刻み(この場面で 8.5e-7 から 1.7e-6 メートル)より小さく、絶対座標へ足すと丸めで0か1刻みになり、その1刻みが速度へ 1刻み ÷ 刻み幅 として現れて次の細分の予測へ入ることである。第1段階の倍精度の参照計算が測れないと書いた「座標の量子化そのものの寄与」が、まさにこれである。**候補Dは契約どおりに実装したが周期を消さない。理由は残差の測り方が位置の量子化のとびを写さないためである。**
