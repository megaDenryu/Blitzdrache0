# M11計測記録 2026-07-23

この文書は追記専用の計測記録である。M11の固定ベンチ結果と、結果から確定した判断を残す。

## 固定ベンチ1回目

- コマンド: `cargo xtask bench`
- 実行条件: リリースビルド、DamagedHelmet、粒子トイ有効、固定カメラ、600フレーム
- 集計条件: 先頭120フレームを除く480標本。CPU側はFIFO提示待ち込みのフレーム開始間隔、GPU側は60フレーム移動平均
- 実行環境: NVIDIA GeForce RTX 3080 Ti、3840×2160、60Hz、ドライバー32.0.15.9621
- 実行結果: 正常終了、Vulkan validationエラー・警告0件

### CPU側フレーム間隔

| 指標 | 実測値 |
|---|---:|
| 平均 | 18.0958ms |
| p50 | 16.7057ms |
| p95 | 33.2550ms |
| p99 | 34.8432ms |
| 最大 | 38.4203ms |
| 25ms超過 | 42回 / 480標本（8.75%） |

平均間隔は55.26fps相当である。中央値は60Hzの1更新間隔に一致する一方、悪化側5%は約2更新間隔になったため、現条件では60fps安定を満たしていない。
