# 妄想が世界を書き換えるシステムと実現方法（技術・ゲームデザイン案）

> [!NOTE]
> ユーザーメモ「妄想すること自体が世界を形作る再帰構造」を、具体的なゲームシステム・技術実装としてどう落とし込むかの具体策まとめ。

---

## 1. コンセプトの解釈
「妄想・考察が世界を形作る」とは、単なるフレーバーテキストではなく、**「プレイヤーの思考・解釈・推理が、実際のゲーム空間やストーリーの物理法則を決定・変化させる体験」** を指します。

---

## 2. 具体的実現アプローチ（3つの提案）

### アプローチA: 【思考手帳（解釈の選択）によるマップ変容システム】
- **体験**:
  - プレイヤーが謎の遺跡や遺物を見たとき、「手帳（思考マップ）」を開き、それをどう解釈（妄想）するかを選択・接続する。
  - 例: 奇妙なマークを見て「①古代の太陽のシンボル」「②水脈の地図」「③巨人の眼」のどれと解釈するか。
- **作られ方（技術実装）**:
  - フラグ分岐＋エリア切替（プレハブ置換）。
  - プレイヤーが選択した解釈タグに応じて、次のエリアのグラフィック、ライティング、出現するギミック（太陽光パズル / 水流パズル / 巨人の仕掛け）が動的に切り替わる。
  - **メリット**: 複雑なAIを使わず、古典的なフラグ管理で「自分の妄想で世界が変わった」圧倒的感覚を作れる。

### アプローチB: 【妄想ビジョン（オーバーレイ）の物理実体化】
- **体験**:
  - 水キャラが「妄想モード（視点切替）」に入ると、モノクロ・線画の「妄想の世界」が重なる。
  - 妄想モード中、存在しないはずの「妄想の橋」を描いたり、「妄想の雨」を空にイメージする。
  - 妄想を解除して現実に戻ると、**イメージした橋や水たまりがそのまま実体化して現実に残る**。
- **作られ方（技術実装）**:
  - レンダリング層（シェーダー/ポストプロセス）の切り替え。
  - 妄想モードで配置・描画したオブジェクトのコライダーとメッシュを、現実レイヤーに Instantiate（実体生成）する。
  - **メリット**: アクションパズルとして直感的で、「水」という幻想的なキャラクターに完璧にマッチする。

### アプローチC: 【マダミス仮説の「真実決定エンジン」】
- **体験**:
  - 事件や世界の謎に対して、プレイヤーがバラバラの証拠を組み合わせて「こうだったに違いない！」という仮説（妄想）を組み立てて提出する。
  - その仮説が論理的に矛盾していなければ、ゲーム側が**「その仮説を世界の歴史・真実として確定」**し、NPCのセリフや今後の展開がそれに上書きされる。
- **作られ方（技術実装）**:
  - ルールベースの条件グラフ（DAG）。
  - 「動機」「凶器」「アリバイ」の組み合わせが成立するか判定し、成立した仮説を正解世界線として登録する。
  - **メリット**: 「プレイヤーが考えた通りのストーリー」になり、究極のマダミス没頭感が生まれる。
