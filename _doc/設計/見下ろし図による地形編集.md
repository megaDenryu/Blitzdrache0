# 見下ろし図による地形編集

チャンク編集に、上から見た図の上で地形を描く2つの方式(等高線・粗マス)を足す設計正本である。既存の三次元の筆(造成筆致・材質の筆致)は残し、この2方式はその上に足す追加である。生存型文書であり、実装とずれたら実装に合わせて直す。ゲーム制作アーキテクチャの判断7(地図の正本を持ち、3D地形はその導出物とする)を、エディターの操作として実現する第一歩である。

`参照: _doc/設計/ゲーム開発用エディター基盤.md`、`_doc/設計/ゲーム制作アーキテクチャ.md`「判断7」、`_doc/計画/ゲーム開発用エディター計画.md`「受理の形」

## 目的

ハイトマップは上から見た1枚の絵であるから、上から描く道具があれば、狙った場所へ狙った高さと地表材質を正確に置ける。三次元の筆は表面をなでる作業に向き、見下ろし図は輪郭と領域を決める作業に向く。どちらかを選ぶ話ではなく、同じ高さ格子と材質重み格子を相手にする道具を増やす。

この工事が成立させるのは次の3つである。

1. **人が見下ろし図の上で等高線を描き、粗マスを塗り、そこから高さ場と地表材質を生成できる**
2. **AIが同じ操作を編集コマンドとして画面なしで積める。** 操作の意味が画面用とAI用で割れない(エディター基盤の判断1)
3. **等高線・粗マス・高さ場は相互に導出できる。** 等高線で大枠を作り、粗マスで地表材質を塗り分け、三次元の筆で細部をなでる組み合わせが自由にできる

## 語彙

- **見下ろし図**とは、1チャンクを真上から見た二次元の編集面のことである。高さ場の標高と地表材質の識別色を下地に描き、その上に等高線と粗マスを重ねる
- **等高線**とは、見下ろし図に描く、1つの高さを持つ折れ線のことである。開いていても閉じていてもよく、線上の高さがその値であるという拘束を表す
- **粗マス**(旧称: 大升。2026-09-04に改称)とは、見下ろし図で高さと地表材質を塗る単位であり、高さ格子の升目を縦横同数まとめた正方形のことである。既存の語「升目」は高さ格子の1升(格子点4つで囲む正方形)を指すため、それより粗い塗りの単位を別の語にする
- **粗マスの塗り**とは、粗マスごとに置いた高さと地表材質の層の集まりのことである。塗っていない粗マスは高さも層も持たず、生成のときにその場所の高さ場と材質重みを変えない
- **見下ろし図の下書き**とは、1チャンクの等高線一覧と粗マスの塗りをまとめた編集資源のことである。高さ場と材質重みの正本ではなく、正本を生成するための入力であり、チャンク構造のJSONへ併存して保存する
- **下書きと正本の揃い**とは、下書きから生成した後に高さ場・材質重み・下書きのどれも変わっていない状態のことである。揃っていないときは見下ろし図が「下書きが新しい」か「正本が新しい」を表示し、揃えるのは人かAIの明示の操作である

## 主要な設計判断

### 判断1: 正本は高さ格子と材質重み格子に据え置き、下書きは併存保存する編集資源にする

ゲーム制作アーキテクチャの判断7は等高線を含む地図を正本にする方向を示すが、この工事では正本を移さない。理由は3つある。既存の16枝の編集コマンドと三次元の筆がそのまま生き残ること、アセットコンパイラと編集サーバーが読むバイナリ資源(`高さ格子.f32raw`・`材質重み.u8raw`)を変えずに済むこと、そして三次元の筆で手直しした結果を等高線へ逆写像すると必ず情報が落ちるため、正本を下書きに置くと筆の結果を保存できないことである。

下書きはチャンク構造のJSONへ`見下ろし図の下書き`として足す。下書きを持たない旧版の保存物は空の下書きとして読む(チャンク構造の版の移行の慣行に従う)。

### 判断2: 下書きの編集と生成はどれも編集コマンドである

AIが人と同じ操作をできる条件は、操作がすべて編集コマンドの枝であることである。下書きを画面だけの状態にすると、AIは等高線を描けず、Ctrl+Zで線の追加と生成が別々に戻らない。そのため次の8枝を編集コマンドへ足す。

| 枝 | 引き受けること | 差し戻しに持つもの |
| --- | --- | --- |
| 等高線を追加する | 高さと頂点列を持つ等高線を1本足す | 追加した添字 |
| 等高線を変更する | 添字の等高線の高さと頂点列を丸ごと差し替える | 変更前の等高線 |
| 等高線を削除する | 添字の等高線を消す | 消した等高線と添字 |
| 粗マスを塗る | 粗マスの一辺と塗る粗マスの一覧を持ち、複数の粗マスへ高さ・層・またはその両方を一括で置く。高さも層も無い項目は塗りを消す。一辺が下書きの一辺と違うときは判断4のとおり塗りを空にしてから置く | 変更前の粗マスの一辺と塗りの全体 |
| 等高線から高さ場を生成する | 等高線一覧を拘束にして高さ格子を丸ごと作り直す | 変更前の高さ格子 |
| 粗マスから地形を生成する | 粗マスの塗りから高さ格子と材質重み格子を作り直す | 変更前の高さ格子と材質重み格子 |
| 高さ場から等高線を導く | 高さ格子から一定間隔の等高線一覧を導いて下書きの等高線を置き換える | 変更前の等高線一覧 |
| 高さ場から粗マスを導く | 粗マスの一辺を受け、高さ格子と材質重みから粗マスの塗りを導いて下書きを置き換える | 変更前の粗マスの一辺と塗りの全体 |

1ストロークで1コマンドという判断1の形はそのまま使う。等高線を1本描き終えるまでが1コマンド(`等高線を追加する`)であり、頂点ごとにコマンドを作らない。粗マスも、左ボタンを押してから離すまでに通った粗マスを1つの`粗マスを塗る`へまとめる。

### 判断3: 等高線から高さ場への変換はラプラス方程式の離散解で行う

等高線の各線分を高さ格子の升目へラスタライズし、線が通る格子点をその線の高さに固定する。固定されていない格子点は、4近傍の平均に等しいという離散ラプラス方程式をガウス・ザイデル反復で解く。収束判定は1反復での最大変化が1ミリメートル未満、反復回数の上限は解像度の2乗の10倍とする。129×129の格子ならブラウザで数十ミリ秒に収まる。

格子点への固定は、格子点ごとに1つの高さだけを受け付けるディリクレ型の拘束である。したがって同じ格子点へ複数の等高線の拘束が来たら、その離散問題では両立しないものとして扱う。高さの差が高さの一致とみなす許容差メートル以下であれば同一の拘束として許可し、差がその許容差を超えるときは高さ場の生成を拒否する。拒否は衝突した2本の等高線の添字と格子点の座標と2つの高さを持つ型付きエラー(`等高線の拘束衝突`)で理由を返し、人が見下ろし図の該当の線を直せるようにする。この衝突は2本の線が実際に交差する場合だけでなく、交差しなくても格子への丸めによって別の線が同じ格子点へ落ちる場合にも起こる。高さの一致とみなす許容差メートルは0.1ミリメートル(0.0001メートル)であり、高さをFloat32Arrayで保持することによるfloat32の丸め誤差と演算順序の違いを吸収できる小さい値を選ぶ。**格子の一辺(水平方向の解像度)には比例させない。** 格子の一辺は水平方向の解像度を表す量であり、許容してよい標高差の大きさを決める意味を持たない。比例させると格子が粗いほど大きな矛盾を飲み込むことになり、拘束の意味そのものが格子の粗さで変わってしまう。

**チャンクの外周の格子点は固定値として扱い、変えない。** 隣のチャンクとの縁の一致(重なり帯の全格子点で同じ高さ)を、この生成が壊さないためである。外周に近い等高線は外周の現在値へ向かって急に落ちる面を作るが、それは表示で見えるため人が判断できる。外周を動かす要求が出たら、大域編集からの再切り出しとして別に設計する。

閉じた等高線の内側に他の拘束が無いと、その内側は等高線と同じ高さの平坦な面になる(膜の解の性質)。丘の頂を作るには内側へもう1本高い等高線か、頂点1つだけの等高線を描く。この性質は説明として見下ろし図のヒントへ出す。

等高線が1本も無いときは生成を拒否し、理由を返す。

### 判断4: 粗マスから地形への変換は粗マスの中心の双線形補間で行う

粗マスの中心を制御点として、塗られている粗マスの高さと層を高さ格子の各格子点へ双線形補間で写す。層はその層だけ255の重みとして補間するため、隣り合う粗マスの境界は粗マス1つぶんの幅で自然に混ざる。塗っていない粗マスの制御点はその場所の現在の高さ場の平均と現在の材質重みの平均を使う。周囲4つの制御点がどれも塗られていない格子点は現在値をそのまま残す(平均で補間し直すと塗っていない場所の起伏まで消えるため)。これにより塗っていない粗マスの中は変わらず、塗った粗マスと塗っていない粗マスの境も滑らかに繋がる。

外周の格子点の扱いは判断3と同じで、変えない。

粗マスの一辺は「高さ格子の升目を縦横いくつまとめるか」を表す正の整数であり、チャンクあたり格子解像度を割り切る値だけを受け付ける(既定は8。2メートル刻みの格子なら16メートルの粗マス)。一辺を変えると塗りの意味が変わるため、一辺の変更は下書きの粗マスの塗りを空にしてから行う。

### 判断5: 逆変換は等値線抽出と升内平均で行い、情報が落ちることを前提にする

高さ場から等高線を導くときは、指定した間隔(既定2メートル)の各高さについてマーチングスクエア法で等値線を抽出し、ダグラス・ポイカー法で許容誤差0.5メートル以内に頂点を間引く。升目の角の高さがちょうど等値のときに出る長さ0の線分は連結を途切れさせるため、抽出の段で捨てる。導いた等高線から生成し直しても元の高さ場は戻らない(間隔より細かい起伏は落ちる)。

高さ場から粗マスを導くときは、粗マスに含まれる格子点の平均を高さに、重みの合計が最大の層を層にする。

どちらも下書きを丸ごと置き換える。人が描いた線と混ぜないのは、混ぜた結果に責任を持てる規則が無いためである。

### 判断6: 見下ろし図は中央のエディタ領域で三次元と切り替え、二次元キャンバスの部品を画面層に新設する

エディター基盤の判断14に従い、見下ろし図は編集対象そのものであるから中央のエディタ領域へ置く。三次元ビューとの切替は操作帯に置く。同時に並べないのは、片方の変更を他方へ映す配線を2倍に増やさず、どちらの面にも同じ編集モデルを読ませれば足りるためである。

SengenUIに二次元キャンバスの部品は無い。HTMLのcanvas要素を包む部品を画面層に新設し、`CanvasRenderingContext2D`は画面層の中に閉じる。submoduleへ足さないのは、この部品を使うのが今のところチャンク編集だけであり、他のツールで要求が出た時点で共通化を判断するためである。

見下ろし図の視点の操作はエディター基盤の判断13と揃える。ホイールがズーム、中ドラッグがパン、左ボタンが編集である。見下ろし図に回転は無い。

### 判断7: 設定は右サイドバーへ、モードは編集の操作だけを切り替える

チャンク編集のモードに`等高線`と`粗マス`を足す。三次元ビューの表示中にこの2モードを選ぶと表示面を見下ろし図へ切り替えるが、逆に三次元のモードを選んでも表示面は変えない(視点のためにモードを押させない)。Altキーのモード循環は大域編集と共有する工程であるため表示面を切り替えない。等高線モードでは左クリックで頂点を置いて線を描き、既存の頂点をドラッグで動かし、線を選ぶ。粗マスモードでは左ドラッグで通った粗マスを塗る。

右サイドバーの等高線パネルには、選んだ線の高さの入力、等高線を導くときの間隔、「高さ場を生成する」「高さ場から導く」、下書きと正本の揃いの表示を置く。粗マスパネルには、粗マスの一辺、置く高さの入力、置く層の選択、塗りを消す切替、「地形を生成する」「高さ場から導く」、揃いの表示を置く。

等高線パネルと粗マスパネルは、それぞれの一番上に選択中の対象の欄を置く。等高線パネルの欄は、選んだ線の高さの入力・頂点数・閉じているか・線の長さ(メートル、小数第1位)・削除ボタンを持つ。粗マスパネルの欄は、選んだ粗マスの(列,行)・塗った高さの入力・塗った層の選択・その粗マスの現在の高さ場の升内平均と重みが最大の層(読み取り専用)・塗りを消すボタンを持つ。どちらの欄も、選択が無いときはクリックして選ぶよう促す案内文だけを表示する。

粗マスモードの左ボタンは、押してから離すまでの移動が小さいとき(押した粗マスと同じ粗マスのまま、画素で数ピクセル以内で離したとき)は1升を選択したことにし、それ以外は従来どおり通った粗マスを塗る。エディター基盤の判断13(左クリックは選択、左ドラッグは配置)に揃える判断である。生成や下書きの変更で下書きが置き換わっても、選択中の粗マスの(列,行)は一辺の升目数が変わらない限り保つ。一辺が変わったときは(列,行)の指す場所が変わるため選択を外す。

見下ろし図の中で選択中の等高線と選択中の粗マスは、それぞれ強調色の線と枠で描く。

見下ろし図に描く高さの数字は、小数第1位で丸める。絶対値が100以上のときは整数にする(高さ場から粗マスを生成すると小数点が大量に並んで見にくいというオーナー判定への対処である)。粗マスの高さの数字は、その文字の幅が粗マスの描画幅の9割を超えるズームでは描かない。等高線の高さの数字も同じ書式化の関数を通す。

### 判断8: 初版はチャンク編集だけを対象にし、大域編集への適用は要求が出てから設計する

大域編集の高さ場(マザーハイトマップ)は地表材質を持たず、外周の固定という制約も無い。同じ下書きの型で表せるが、置き場(大域世界構造)と外周の規則が違うため、初版では扉として残す。

## 正準の一仕事

受理の形(2026-08-28制定)に従い、この道具の存在理由を1本の物語にする。この1本が丸ごと通らないうちは受理しない。

```
チャンクを開く → 見下ろし図へ切り替える → 等高線を3本描いて高さを付ける
→ 高さ場を生成する → 三次元で形を確かめる → 粗マスで岩を塗って地形を生成する
→ 保存する → 開き直す → 同じ形と色と下書きが出る
```

同じコマンド列をヘッドレスの一括適用へJSONで渡し、ブラウザで開いた結果と格子が一致することを検収の機械判定にする。

## 操作契約

元になる試作が無いため、実装の前に置く。

- **一仕事**: 上の正準の一仕事
- **主な操作**: 等高線モードでは、左クリックで頂点を置き、ダブルクリックか右クリックで線を閉じずに終える、始点をクリックして閉じる、頂点を左ドラッグで動かす、線分を左ドラッグで動かす(両端の頂点が一緒に動く)、線をクリックして選び右サイドバーで高さを打つ、Deleteキーで選んだ線を消す。粗マスモードでは、右サイドバーで高さと層を決めてから左ドラッグで塗る
- **視点と選択の共通操作**: ホイールでズーム、中ドラッグでパン。選択は左クリック。三次元と見下ろし図の切替は操作帯のボタン
- **操作したとき何が返るか**: 線を描き終えると線がその高さの文字とともに残る。生成すると下地の標高の色が変わり、揃いの表示が「揃っている」になる。三次元の筆で触ると揃いの表示が「正本が新しい」に変わる。生成できないときは理由を操作帯の下の帯へ出す
- **最初にどこを触れば始められるか**: 操作帯の「見下ろし図」ボタン。押すとヒントに「左クリックで等高線の頂点を置く」と出る

## 検収の形

- 編集モデルの単体試験: 1本の水平な閉じた等高線から生成した内側が等高線の高さで平坦になること、2本の同心の等高線の間が単調に変わること、外周の格子点が変わらないこと、粗マスの塗りが塗っていない粗マスの格子点を変えないこと、粗マスの層の境界で重みの合計が255を保つこと、等高線を導いてから生成し直したときの誤差が間隔の半分以内であること
- 操作コマンドの試験: 8枝それぞれの適用と差し戻しで状態が元へ戻ること、同じコマンド列をブラウザの適用とヘッドレスの適用へ流した結果が一致すること
- 編集サーバーの統合試験: 下書きを持つチャンク構造の保存と読込の往復、下書きを持たない旧版の読込が空の下書きになること、粗マスの一辺が解像度を割り切らない保存を拒否すること
- 受理: オーナーが正準の一仕事を通す
