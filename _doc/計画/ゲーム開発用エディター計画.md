# ゲーム開発用エディター計画

ブラウザで動くオープンワールド編集の道具をこのリポジトリへ立てる工事の正本である。設計は `_doc/設計/ゲーム開発用エディター基盤.md` が持つ。2026-08-19のオーナー指示(旧`tmp計画.md`。本文書へ置き直して破棄した)で開始した。

## 発端と素材

Gemini 3.7 Flashが試作した1ファイルHTMLのモックアップ2本が、作る内容の定義である。`_doc/ゲーム開発用エディター計画/` に参照素材として置く(ログ型。追記も改稿もしない)。

- `ワールドグリッドマネージャー.html`: 1024m四方(4×4チャンク)を513×513の連続マザーハイトマップで造成し、広域道路スプラインを敷き、境界クラック防止の1px重複共有(129×129)で16チャンクをRAW16+JSON+世界マニフェストへ切り出す
- `ワールドパイプラインエディター.html`: 256mチャンクの造成・地表材質4層の塗り分け(急勾配の岩肌自動ベイク・道路下の泥自動ベイク)・道路スプラインと切土盛土・建物配置と基礎の平坦化・ポアソンディスク散布と除外

これをTypeScriptへ移植し、開発用エディターサーバー(axum)から配信してブラウザで使う。AIと人間が同じ口から操作でき、永続化はゲームプロジェクトごとの保存先に差し替えられる(要求の全文と実現の形は設計正本を見る)。

## 段割り(依存順)

- **段1: 環境構築(Sonnet)。** SengenThreeの空リポジトリ新設(megaDenryu/SengenThree、public、SengenUIと同じ配置規約)→Blitzdrache0へ `crates/editor_server`(axumの骨格)と `editor_web`(Vite+TS)を新設→submodule3本(SengenUI・VscodeShellLayout・SengenThree)を `editor_web/submodules/` の標準配置で導入→eslint-plugin-boundariesの層強制とts-rs契約鮮度検査の骨格→`cargo xtask editor` の登録→空画面の配信が起動することの確認。完了条件: xtask editorで外殻が表示され、verifyが全緑
- **段2: 型契約と保管庫。** 編集資源の型(大域世界・チャンク・道路・建物・散布)と操作コマンドの型、`プロジェクト保管庫`traitとファイル実装、RESTの読み書き口、ts-rs生成。完了条件: 契約鮮度検査と保存往復テストが緑
- **段3: SengenThreeの汎用宣言層。** SengenUIの兄弟にあたる、Three.jsの上の薄い宣言的配置層を汎用ライブラリとして作る(2026-08-19のオーナー是正: 「エディターに要る部品だけの最小API」という枠組みは誤り。範囲はThree.jsのドメインから決め、エディターは最初の利用者・検収のひと仕事にすぎない)。範囲は場面木の宣言的配置(childs様式)・部品の基底と配線・ジオメトリとマテリアルの所有と破棄(dispose漏れ防止)・個体群(InstancedMesh)・カメラと操作・光源・レイキャスト由来のポインタ事象・フレームループ。**地形メッシュ・道路の帯のようなエディター固有の部品は入れない**(エディターの画面層がこの上に作る)。SengenUIへは依存しない(配線ポートは同じ様式を自前で持つ)。SengenUIと同様に1ファイル100行制限は課さない(2026-08-19オーナー指示)。完了条件: 型検査とテスト(WebGLを要しない範囲)の緑・破棄の所有のテスト・READMEのAPI文書
- **段4: 移植(agy反復)。** 2エディターの編集モデル・操作コマンド・画面をモックアップから移植。agyへは自己完結仕様書で委譲し、自己レビュー→修正を反復。親は各回の成果を現物検収(報告は信用しない)
- **段4.5: 画面モデルの再設計(エクスプローラーと文書タブ)。** 2026-08-19のオーナー指示(「編集対象は階層構造で、エクスプローラー的なもので開き、対象ごとにタブが開くべき。使っていて『はてな?』が多い」)による。設計正本の判断7が正本。内訳: (a)VscodeShellLayoutへアクティビティ連動の左サイドバーを汎用実装(ライブラリ側の既知の未実装) (b)エディターのエクスプローラー木(大域世界・チャンク一覧)と対象ごとのタブ化・前面タブだけ描画ループを回す規律への再配線 (c)親の実機ウォークスルーで「はてな?」を列挙して潰すデザイン調整の周回
- **段5: 最終の詰め(親)。** 規約適合の総仕上げ・命名/構造チェック員の検査・「その道具でひと仕事通す」検収(エディター制作スキル。何も無い状態から造成→塗り→道→配置→保存→読み直し→書き出しまで)
