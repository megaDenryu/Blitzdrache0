# 検査の網羅台帳

命名と構造の検査が、このリポジトリのどこまでを検査済みかを記録する生存型文書である。2026-08-11のオーナー指示(「触るときに直すだけでは、誰も触らないコードが永遠に未検査で残る。日常的にローラー的に監査を派遣すべきだ」)で制定した。正本の規約はグローバルCLAUDE.mdが持つ(該当箇所は「日本語命名の受理条件」にある運用の箇条書きと、「プリミティブ執着禁止はパス・テキスト・名前にも適用する」)。

## 運用

- **記録の無い領域は未検査として扱う。** この台帳がローラー検査の完了を定義する
- 検査は2系統で進む。**差分検査**は委譲成果の検収時に命名チェック員+構造チェック員が常時行う(2026-08-09以後の全変更が対象)。**ローラー検査**はセッションの待ち時間に未検査領域へ検査員を派遣して行う
- 記録の単位は「領域(クレートまたはディレクトリ)×検査の軸(命名・構造)」であり、検査した日付・時点のコミット・結果の要約を書く
- 検査で見つかった違反の是正は、機能変更と別コミットで行う(リネーム員・実装員)。是正が済んだら結果の欄を更新する
- 検査の軸の定義: **命名**はグローバルCLAUDE.md「日本語命名の受理条件」の8条件。**構造**は同「サービスの依存保持とコールバックの限定」「デザインパターンの既定」「プリミティブ執着禁止はパス・テキスト・名前にも適用する」(自由関数の許容2条件・プリミティブ執着・値オブジェクト様式・&mut連鎖・暗黙のグローバル依存・凝集を失った定数)
