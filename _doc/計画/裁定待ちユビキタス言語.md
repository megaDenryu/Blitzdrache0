# 裁定待ちユビキタス言語

裁定待ちユビキタス言語とは、実装の途中でAIが新しく作り、オーナーの裁定をまだ受けていない語のことである。

実装員は、既存の語では表せない概念に出会ったとき、その場で名前を決めてよい。ただし決めた名前は案であり、合意済みの語彙ではない。このファイルはその案を置く場所である。

`_doc/計画/ユビキタス言語.md` は、対話で合意した語彙を記録する正本である。親と実装員は、裁定を受けていない語をそちらへ書いてはならない。
グローバルCLAUDE.md「専門用語の表記」が求める「定義なしで新語を使い始めるのは禁止」は、このファイルへの登録で満たす。

手順の全文はプロジェクトのCLAUDE.md「新しいドメイン概念と語彙の導入」にある。

## 書き方

1件につき次の5つを書く。語を見出しにし、残りの4つを箇条書きにする。

- **区切られたドメイン**: 共通・描画・物理・ゲーム実行・ECS・資産ストリーミング・エディター・開発基盤のどれか。1語1義はこの範囲の中で成り立つ規律であり、区切られたドメインが違えば同じ表記が別の語でありうる。詳細はCLAUDE.md「区切られたドメイン」にある
- **暫定の定義**: 「Xとは〜のことである」の形で書く
- **使っている場所**: その語を識別子または文書で使っているファイルのパス
- **既存語で表せないと考えた理由**: どの既存語を検討し、なぜ足りないと判断したか

裁定が済んだら、親はこの節から項目を消す。親は、採用ならユビキタス言語へ定義を移し、必要なリネームを別のコミットで行う。親は、却下なら既存語へ戻すか、概念そのものを畳む。

## 裁定待ちの語(2026-09-20時点で4件。PR #138 の実装員と親が作った語)

### 歩行方向

- **区切られたドメイン**: ゲーム実行
- **暫定の定義**: 歩行方向とは、旅行者が歩く向きを表す、東の比率と北の比率の二乗和が1である値オブジェクトのことである。生成の口はキーボード歩行入力からの導出`キー入力から導く`だけであり、相反するキーが相殺して零になれば向きは無い(`None`)。斜めの入力は長さを1へ正規化する。同型の`f32`を2つ並べる生成の口を置かないのは、東と北を取り違えても型が通るためである
- **使っている場所**: `crates/blitz_esca/src/walking_direction.rs`(定義)・`crates/blitz_esca/src/traveler.rs`・`crates/blitz_esca/src/traveler_movement.rs`・`crates/blitz_esca/src/tests/walking_direction_tests.rs`・`_doc/設計/Esca/設計正本.md` 4.4
- **既存語で表せないと考えた理由**: 「方向」「向き」を検討した。長さが1であることを不変条件に持ち、生成の口をキーボードの入力からの導出だけに限る値オブジェクトであることを、裸の方向では言えなかった

### 移動可能範囲の指定

- **区切られたドメイン**: ゲーム実行
- **暫定の定義**: 移動可能範囲の指定とは、移動可能範囲を作るための、東の最小・最大と北の最小・最大を公開フィールドで持つ指定のことである。`検証する()`が各軸の最小が最大以下であることと端が数値であることを確かめ、通れば移動可能範囲になり、破れは`移動可能範囲の生成の失敗`(最小が最大を超えている軸と値、数値でない軸)で返る。移動可能範囲そのものはフィールドを私有にし、この検証を通らずには作れない
- **使っている場所**: `crates/blitz_esca/src/traveler_boundary.rs`(定義)・`crates/blitz_esca/src/tests/traveler_boundary_tests.rs`・`_doc/設計/Esca/設計正本.md` 4.2・4.4
- **既存語で表せないと考えた理由**: 「移動可能範囲」を検討した。移動可能範囲は検証済みの値であり、検証の前の公開フィールドの入力とは別の型である。検証の前後を同じ語で呼ぶと、検証を通らずに作れないという不変条件が名前から読めなかった

### 経過時間

- **区切られたドメイン**: ゲーム実行
- **暫定の定義**: 経過時間とは、遷移関数へ渡す、有限かつ0以上の時間のことである。`blitz_math::秒`を`経過時間::生成する`で検証して包んだ値オブジェクトであり、負・NaN・無限大は`経過時間の生成の失敗`で拒む。遷移関数が負の時間で逆向きに動いたり、数値でない時間で現在地を汚したりしないために置く。Esca第1段階の遷移パラメータ(`MParameter`)が持つ唯一のプロパティである
- **使っている場所**: `crates/blitz_esca/src/elapsed_time.rs`(定義)・`crates/blitz_esca/src/ontology.rs`・`crates/blitz_esca/src/traveler_movement.rs`・`crates/blitz_esca/src/tests/elapsed_time_tests.rs`・`_doc/設計/設計オントロジー.md` 3.5.1・4.5・`_doc/設計/Esca/設計正本.md` 4.1・4.4
- **既存語で表せないと考えた理由**: 「秒」「刻み幅」を検討した。`blitz_math::秒` は符号も有限性も持たない生の量であり、遷移に渡してよい(有限かつ0以上)ことを型で言う語が要った。刻み幅は固定刻みの語であり、可変の経過を指さない

### 旅行者の現在地の生成の失敗

- **区切られたドメイン**: ゲーム実行
- **暫定の定義**: 旅行者の現在地の生成の失敗とは、旅行者の現在地の東または北が有限な数値でない(NaN・無限大)ときに`旅行者の現在地::生成する`が返す失敗のことである。NaN は比較がすべて偽になり移動可能範囲の制限で捕まらないため、生成の口で閉じる
- **使っている場所**: `crates/blitz_esca/src/traveler_error.rs`(定義)・`crates/blitz_esca/src/traveler.rs`・`crates/blitz_esca/src/traveler_movement.rs`・`crates/blitz_esca/src/tests/traveler_invariant_tests.rs`・`_doc/設計/設計オントロジー.md` 3.5.9・`_doc/設計/Esca/設計正本.md` 4.1・4.4
- **既存語で表せないと考えた理由**: 既存の失敗の型の名前の様式(`移動可能範囲の生成の失敗`・`歩行の規則の生成の失敗`)に揃えた。現在地の座標が有限でないことを表す型付きエラーを指す語が無かった
